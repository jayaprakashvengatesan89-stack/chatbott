CRIC — Full Frontend + Backend

1. Extract the ZIP and open this folder in VS Code.
2. Open PowerShell in the project folder.
3. Run: pip install -r requirements.txt
4. Put your Gemini API key in .env.
5. Run: python app.py
6. Open: http://127.0.0.1:5000

The frontend and Flask backend are already connected.
Firebase/Firestore is prepared as the next integration step for cricket rankings and statistics.
